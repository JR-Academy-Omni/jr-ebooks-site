HOW TO USE

毕业了，第一份工作应该怎么找？

这不是一本岗位百科，也不是“固定天数上岸”计划。它帮助缺少澳洲本地专业经验的国际毕业生，建立一条可以执行、检查和调整的求职链路。

确认能不能工作

先核对当前签证、毕业后的工作权、期限与岗位身份限制。

确定投什么

从专业、课程、经历、城市和真实岗位名称确定主攻、备选与过渡方向。

对照招聘要求找差距

收集同类岗位，分清必须满足的条件、常见能力和单家公司的特殊偏好。

积累相关实习与项目

优先争取与目标岗位相关的实习、兼职和真实项目；没有实习时，准备一个完整、能够展示和讲解的项目。

准备材料

用一份基础简历，按岗位调整首屏、项目顺序与关键词。

持续投递与面试

组合官网、招聘平台、学校渠道与 Networking，记录每次结果。

根据申请结果调整

没有回复、没有通过初试、技术面或终面的原因不同，不要一遇到拒绝就盲目再学一门课。

这本书适合谁适合正在澳洲读书、即将毕业或刚毕业，并希望寻找第一份 Graduate 或 Junior 工作的国际学生。书中以 IT 与数字岗位作为重点案例；其他专业的读者也可以使用其中的选岗、分析招聘要求、准备简历、投递和面试方法。需要职业注册的岗位，还应查询对应注册机构的最新要求。
BEFORE GRADUATION

毕业前最重要的准备：相关实习与项目

对缺少正式行业经验的毕业生来说，只有学历和技能列表通常不足以让雇主判断你能否完成工作。相关实习、兼职和项目，是简历与面试最重要的内容来源之一。

第一优先：相关实习或兼职

实习、假期实习项目、校内岗位、研究助理或相关兼职，可以帮助你接触真实团队、工作流程和业务要求。

第二选择：校企合作与真实项目

毕业综合项目、学生咨询、社团或志愿项目，只要有真实问题、明确分工和可以检查的结果，都能成为求职经历。

没有实习时：完整自主项目

选择一个与目标岗位有关的问题，完成可运行或可展示的成果，并保留过程、测试、修改和反思，而不是照着教程复刻。

毕业前先完成四件事

确定一个主攻方向

查看 10-20 条真实招聘信息，了解常见工作内容，再选择一个主攻方向和一个相近方向。暂时不需要决定一辈子的职业。

寻找与方向相关的经历

同时查看实习、学校与企业合作项目、毕业综合项目、校内岗位、社团、志愿项目和小企业项目，不要只等待大公司的正式实习。

让项目对应岗位工作

开发岗位准备可运行应用；数据岗位展示从原始数据到结论的过程；BA、QA、市场、会计和运营岗位则准备与实际职责相符的案例。

把经历整理成可以申请的内容

保存代码、报告、流程图、看板、测试记录或作品，并能说明问题、个人职责、具体行动、检查方式和最终结果。

你目前的情况下一步重点
还不确定想做什么比较两到三个岗位方向的招聘信息、日常工作和申请条件，不要先报名一堆课程。
方向明确，但没有相关经历优先申请实习和真实项目，同时完成一个与岗位工作直接相关的自主项目。
做过项目，但不会写进简历补充个人职责、过程、检查方式和结果，并准备能够在面试中展示的版本。
已经临近毕业一边申请 Graduate 和 Junior 岗位，一边确认工作权、推荐人、简历和面试案例。
实习不是所有毕业生岗位的硬性条件，但相关经历会明显增加简历的可信度。
没有实习时，应尽量用真实、完整、与岗位相关的项目补充。部分实习和校企合作只接受在读学生，不要等毕业后才第一次查看。

雇主更关心你做过什么、怎样检查结果、能否解释过程，以及能否与他人合作。实习有帮助，但相关程度和个人职责比公司名更重要。

毕业日期是学习节点，不是招聘起点。许多 Graduate Program 会在正式入职前 6—12 个月完成申请、测评和录用。

如果等拿到毕业证再研究岗位，可能已经错过一轮结构化 Graduate Program。但这不等于“毕业后没有机会”：普通 Graduate Role、Junior Role、Fixed-term、Contract 和中小企业招聘会全年出现，只是寻找方式不同。

先分清六种入口

入口通常特点你要注意
Graduate Program批量招聘、轮岗、统一测评，通常提前很久开放。毕业年份、身份、成绩和地点要求。
Graduate Role单一团队招毕业生，开放时间更分散。岗位技能比统一项目更具体。
Junior / Entry-level不一定限定毕业年份，可能要求少量经验。“Junior”标题不保证要求真的初级。
Internship可能限定在读身份，也可能转正。确认是否要求仍在校和合法工作时数。
Fixed-term / Contract按照固定期限或具体项目聘用，可能是进入行业的一种方式。合同多长、工资怎样计算、是否包含 super，以及能否续约。
普通社会招聘全年开放，按团队即时需求招聘。用相邻经验和项目证明可立即贡献。
行业缺人，不等于毕业生容易找到工作。
即使职位广告增加，雇主仍会按照工作地点、工作权、经验要求和岗位匹配度筛选。不要只看“热门”或“紧缺”标签，要逐条确认具体岗位的要求。

这些数字不是为了制造恐慌，而是提醒你：学历名称和技能列表还不够。雇主还会看工作权、岗位匹配度、实际项目、沟通能力，以及你能否完成团队交给你的工作。

CHAPTER 02

毕业后能不能在澳洲合法工作

求职第一道门不是简历，而是当前签证是否允许你工作、条件是什么、这种工作权能维持到什么时候。

确认当前有效签证

不要只看旧邮件或预计日期。使用 VEVO 查看当前生效的签证、到期日和附加条件。

确认实际工作条件

签证可能限制工作时数、工作类型或其他条件。课程完成、放假与毕业典礼不是同一个概念。

确认毕业后的安排

485 是符合条件的国际毕业生可能申请的临时签证，并非毕业自动获得。申请资格和期限以 Home Affairs 为准。

再判断岗位资格

法律上能工作，不代表所有岗位都能申请。雇主还可能要求澳洲公民、永久居民（PR）、长期工作权或政府安全审查资格。

三个经常被混淆的问题

能不能合法工作？由当前签证和签证条件决定，应通过 VEVO 和签证批准信确认。
雇主能不能录用？还取决于岗位自己的身份、合同期限、背景调查和安全许可要求。
雇主会不会担保？“现在无需担保即可工作”与“未来愿意担保”是两件事，不能用口头可能性替代正式承诺。
每个人的签证情况不同如果你的签证正在审理、即将到期或附带特殊条件，不要直接套用同学和网络上的经验。请先通过 VEVO 查看自己的实际签证状态；需要判断个人申请资格时，向澳洲内政部、注册移民代理或移民律师确认。

官方查询：澳洲内政部“工作限制”“485 毕业生临时签证”和“VEVO 签证状态查询”。

CHAPTER 04

常见 IT 入门岗位（一）

你不需要把下面所有方向都学一遍。先了解每类工作平时做什么，再选一个与自己的课程、项目和兴趣最接近的方向。

SOFTWARE

软件开发

常见职位：Frontend / Backend / Full-stack Developer

  • 主要做什么：开发网站、应用程序和后台系统，并修复程序问题。
  • 招聘常看：编程语言、网页与接口、数据库、Git、测试和调试。
  • 毕业生怎么准备：完成一个可以实际运行的项目，并能解释自己负责的部分、测试方式和技术选择。
DATA

数据分析与商业报表

常见职位：Data Analyst / BI Analyst / Reporting Analyst

  • 主要做什么：整理和分析数据，帮助业务回答“发生了什么、为什么、下一步怎么办”。
  • 招聘常看：Excel、SQL、Power BI/Tableau、数据清洗和表达能力。
  • 毕业生怎么准备：用一份真实或公开数据完成分析，展示数据处理、图表和业务结论。
BUSINESS ANALYSIS

业务分析与系统实施

常见职位：Business Analyst / Implementation Consultant / Systems Analyst

  • 主要做什么：了解业务问题，整理需求，协助技术团队完成系统上线和验收。
  • 招聘常看：流程分析、需求文档、会议沟通、用户测试和跨团队协作。
  • 毕业生怎么准备：用一个案例展示现有流程、问题、改进方案和验收方法，而不只是说自己“沟通好”。
SOFTWARE TESTING

软件测试与质量保障

常见职位：QA Analyst / Test Analyst / Automation Tester

  • 主要做什么：检查系统是否按要求工作，发现、记录并跟进问题。
  • 招聘常看：测试用例、缺陷记录、回归测试、接口和数据库基础；部分岗位还看自动化测试。
  • 毕业生怎么准备：为一个网站或应用编写测试方案、问题报告，并完成一小部分自动化测试。
CHAPTER 04

常见 IT 入门岗位（二）

TECHNICAL SUPPORT

技术支持与应用支持

常见职位：IT Support / Service Desk / Application Support

  • 主要做什么：帮助用户处理账号、软件、设备和系统使用问题。
  • 招聘常看：Microsoft 365、账号权限、基本网络、问题排查、工单和用户沟通。
  • 毕业生怎么准备：整理一组真实的排错过程，说明怎样定位问题、解决问题并记录方法。
CLOUD & NETWORK

云平台与网络

常见职位：Cloud Support / Network Support / Junior Cloud Engineer

  • 主要做什么：维护云环境、服务器和网络，处理部署、权限、监控和故障。
  • 招聘常看：Linux、网络基础、AWS/Azure、脚本和问题排查。
  • 毕业生怎么准备：搭建一个小型云环境，记录部署、权限、日志和故障处理过程。
CYBER SECURITY

网络安全

常见职位：Cybersecurity Analyst / SOC Analyst / GRC Analyst

  • 主要做什么：监控安全风险、分析日志、处理事件，或检查制度和合规要求。
  • 招聘常看：网络、操作系统、身份权限、日志分析和风险意识。
  • 毕业生怎么准备：用实验记录或安全案例说明怎样发现问题、判断风险并提出处理建议。
AI-RELATED ROLES

AI 相关岗位

常见职位：AI Application Developer / Machine Learning Graduate

  • 主要做什么：把 AI 能力接入产品，处理数据，并测试输出是否可靠。
  • 招聘常看：软件或数据基础、模型应用、结果评估、隐私和安全。
  • 毕业生怎么准备：先具备软件或数据基本功，再做一个能说明数据来源、测试方法和失败情况的 AI 项目。

CHAPTER 05

看懂招聘要求：哪些必须满足，哪些可以补

招聘广告也常被称为 JD（Job Description）。不要只看职位名称，要逐项判断自己是否符合申请条件、已经具备什么，以及还需要准备什么。

招聘广告里写了什么应该怎样理解你可以怎么做
Citizenship / PR / clearance必须满足的身份或安全审查条件，通常不能用技能弥补。不符合就暂时不申请，或向招聘方确认。
Degree / graduation windowGraduate Program 可能严格限定专业和毕业年份。检查成绩单、完成日期和海外学历认可。
2—3 years experience结合具体工作判断，这是必须条件，还是雇主对理想候选人的期望。如果主要工作确实做过，可以有选择地申请。
Strong communication通常指澄清问题、记录决策、解释风险。准备有结果的 STAR 故事，不只写“英语流利”。
Specific tool看它是岗位核心平台还是可替代工具。先补高频能力，不为单条广告追每个工具。
AI / automation判断它只是加分项、日常工具，还是这份工作的主要内容。只有申请以 AI 为核心的岗位，才需要重点准备模型应用和结果评估。

不要因为一份招聘广告就改变整个学习方向

CHAPTER 06

用实习和项目展示岗位能力

相关实习、兼职和真实项目，能让简历和面试有具体内容。没有实习时，可以用毕业项目、校企合作、社团、志愿经历或完整的自主项目，说明自己做过什么、负责过什么，以及怎样检查结果。

TECH

求职投递管理器

Full-stack 项目：账号、岗位状态、提醒、筛选、测试与部署。AI 只负责初步提取招聘信息，最终内容由用户确认后保存。

DATA / BUSINESS

招聘数据看板

SQL、Excel/Power BI：清洗岗位样本、统一技能词、检查数据质量并给出业务结论。

BA / QA

系统改进 Case

现状流程、需求、User Story、验收标准、UAT 与缺陷记录；证明你能把问题推进到验证。

任何项目都要回答六个问题

  • 谁遇到了什么问题
  • 你个人负责了什么
  • 为什么选择这种方法
  • 怎样验证结果是正确的
  • 遇到过什么失败或限制
  • 如果继续做，下一步改什么

AI 使用要说明边界

可信表达
我使用 Copilot 起草重复的测试样板；测试策略、断言和权限场景由我定义。
生成内容经过代码 Review、故意失败测试和静态检查后才合并。

不可信表达
使用 AI 大幅提高效率并完成整个系统。

写项目时要真实：没有真实用户就不要写“提升转化率 30%”；团队成果不要全部写成个人成果；教程复刻要说明自己新增和验证了什么。

CHAPTER 07

简历、LinkedIn 与申请材料

简历首先回答三个问题

你要什么岗位

标题、Summary、技能和项目指向同一方向，不写“什么都可以”。

你能做什么

用项目、经历和成果证明，不用“热情、努力、快速学习”等空词。

你是否符合资格

学历、毕业时间、地点和工作权回答一致，不夸大。

弱表达更可信的表达
熟悉 React、Node、AWS 和 AI。用 React、Node 和 PostgreSQL 构建投递管理器；部署 API，并为权限、重复提交和失败重试编写测试。
负责数据分析和报表。清洗订单数据并统一日期和产品的计算方式；用 SQL/Power BI 制作看板，记录 12 条数据检查规则。
具有良好的沟通能力。协调 4 人团队澄清项目范围，把需求拆成任务并每周同步风险，按期完成演示。

一份基础简历，产生岗位版本

  • 先整理全部经历，再选择与目标岗位最相关的内容
  • 根据招聘要求调整个人简介、技能、项目顺序和每条经历
  • 简历里的数字必须能说明来源，不虚构百分比
  • LinkedIn、简历和作品集的目标岗位保持一致
  • 求职信只说明为什么适合这份工作，不复述整份简历
  • 申请政府岗位时，额外检查是否需要回答职位筛选问题

CHAPTER 09

测评与面试：准备真实案例，不背万能答案

常见流程

在线测评或录屏回答

常见于 Graduate Program，可能包括能力测试、情景判断和录制视频回答。

招聘人员初步沟通

通常会问求职动机、沟通、薪资、地点、毕业时间和工作权。

主管或专业面试

会深入询问项目、案例、专业知识或实际工作场景。

评估中心或推荐人调查

可能包括小组协作、展示、背景调查和联系推荐人。

准备 8 个真实经历

失败、冲突、需求不清、时间压力、主动改进、学习新工具、影响他人、处理客户问题。

练习讲清自己的项目

为什么做、自己负责什么、数据从哪里来、为什么这样选择、最难的问题、怎样检查结果、失败过什么。

方向常见考查提前准备什么

CHAPTER 11

Offer、合同与招聘风险

检查项要问清楚
薪资Base、base + super、total package 还是合同日薪？Bonus 是否保证？
合同Permanent、fixed-term、casual 或 contractor？试用期和通知期如何规定？
工作方式办公室天数、搬迁、轮班、on-call 和加班是否明确？
工作权合同期限与当前工作权是否一致？是否存在持续资格条件？
成长直属经理是谁？前三个月主要做什么？是否有导师、培训和晋升机会？
风险是否要求先付费、购买培训、无薪试工或承诺不现实的担保？
国际学生同样享有基本工作权利临时签证持有人也受到澳洲工作场所法律保护。最低工资、工资单和雇佣条件可以通过 Fair Work Ombudsman 官方网站查看。
  • Offer 与合同上的公司、职位、工资和开始日期一致
  • 重要条件已经写进正式文件，不只依赖口头承诺
  • 已经提前与推荐人沟通，并让对方了解目标岗位
  • 不向陌生招聘方提供银行密码或支付所谓“保证金”
  • 不把雇主“可能提供担保”当成已经确定
