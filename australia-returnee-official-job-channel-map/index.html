CHAPTER 01

官方渠道和商业平台，解决的是两件不同的事

发现

商业平台擅长扩大岗位池

看岗位关键词、城市热度、经验要求和市场需求。它适合让你知道“外面在招什么”。

不能直接替代：招聘主体、资格原文、附件、截止时间和最终报名入口。

核验

官方来源负责让你敢行动

确认谁在招、招谁、什么时候截止、需要什么材料、到底在哪里报名。

适合保存：原始公告、岗位表、报名系统和官方咨询入口。

最稳的组合：商业平台发现关键词 → 搜索招聘主体 → 找到原始公告 → 打开报名页 → 记录核验日期。两边不是二选一。

来源可信度：D 级可以发现，A/B 级才能支撑行动

等级来源怎么用不能怎么用
A政府部门、招聘单位、项目主办方原始公告与报名系统作为核心证据；记录发布日期、截止日和核验日不能省略附件和例外条件
B官方公共招聘平台、主管部门专题页、官方高校就业平台发现并交叉核验；尽量回到招聘主体不能把聚合页当最终岗位原文
C高校就业公众号、官方媒体转载作为线索；检查是否完整保留原链接不能只截标题或海报
D商业平台、自媒体、社群转发、聊天截图提取关键词和发布主体不能直接写进“可行动机会”
截图不是证据终点：截图可以帮助你回忆，但没有 URL、发布日期和发布主体，就无法确认它是否仍有效。

EVIDENCE FIELDS

你的监测表不是收藏夹：每条机会至少补齐 14 个证据字段

字段组必须记录为什么
身份机会名称、发布主体、渠道类别防止把集团、子公司、承办平台混为一谈
入口原始公告 URL、报名 URL、官方咨询入口转发页面失效后还能回到源头
时间发布日期、截止时间、时区、checked_on澳洲与中国存在时差，不能只抄“今晚截止”
适用毕业时间、学历/专业、材料、地点先排除明显不适用机会
状态当前状态、证据边界、下一次动作知道它是待核验、可行动还是已结束

一条合格记录长这样

不是：“某国企招海归，8 月截止。”

而是：“张家港市人社局发布地方国企公告；海外申请人需同时核对榜单、学位取得时间、留服认证、就业状态和居留条件；2026 年案例，仅用于演示多条件核验，最终资格由招聘方审核。”

CHAPTER 02

企业校招先建“单位清单”，不要只建“岗位清单”

岗位会下线，企业招聘主页会长期存在。先保存单位的招聘主页，再区分项目、批次、地区和合同主体。

CHAPTER 05

创业赛事、人才项目和普通求职，投入方式完全不同

类型你提交什么常见前提适合谁
普通求职简历、网申材料、测评与面试毕业、专业、经验、材料等岗位条件目标是获得劳动岗位的人
创业赛事商业计划书、团队与项目材料项目阶段、赛道、团队、落地意向已有项目想验证或对接资源的人
人才项目单位申报、项目方案、成果与证明申报单位、全职要求、年龄、入境/回国时间等已有科研、创新或创业项目的人
项目资助不是“留学生个人补贴”：先看资金给个人、团队、单位还是项目；再看是否需要单位申报和评审。

看到 ITEC、人才计划等入口时

先检查是否要求商业计划书、公司或拟注册信息、团队、融资与项目材料。页面能确认的字段有限时，完整资格、赛程和奖励必须回到主办方当期说明。

PROJECT FIT

用 6 个问题，快速判断一个项目值不值得投入

  • 我的目标是找工作，还是推进一个创业 / 科研项目？
  • 是否需要已成立公司、申报单位或落地城市？
  • 是否要求商业计划书、知识产权、成果或融资材料？
  • 年龄、回国 / 入境时间、全职工作等条件是否明确？
  • 资助对象是个人、团队、单位还是项目？
  • 准备成本与截止时间是否匹配？
快速结论 允许放弃

□ 与我的求职目标一致　□ 需要进一步核验　□ 不适用，停止投入

不确定的唯一字段：

普通求职者快速淘汰不适用项目，不是错过机会，而是在保护简历、面试和目标岗位准备时间。

为什么不是越多越好

固定入口太多，你每周不会真的检查。每类先选 3 个：一个国家 / 主管部门入口、一个目标城市入口、一个目标单位或行业入口。连续两周有价值，再加。

你的地图合格标准：每一个入口都能说清“谁发布、我为什么要看、多久看一次、上次什么时候打开”。
TOOL 02

每周监测表：一条机会占一行，证据不齐就不写“可行动”

机会 / 主体原始来源适用人群截止时间状态下一步

checked_on

记录你最后一次打开原页面的日期。不是文章发布日期，也不是别人转发给你的日期。

证据边界

写清这条来源能确认什么、不能确认什么。例如“行动通知能确认行业方向，不能确认岗位仍开放”。

TOOL 03

七种状态，让你的表不会永远堆着“待看”

状态什么时候用下一步
待核验只有线索，尚未取得 A/B 级来源找原始发布主体
可行动原始入口可访问、未截止、基础条件已记录准备或提交
待官方确认公告有歧义，个人资格无法从原文判断通过官方入口咨询并留证
已结束明确超过截止时间或页面显示结束移入归档
入口失效原页面不可访问，未找到官方替代页继续查替代入口，不能自行判定取消
不适用毕业时间、专业、城市、身份或类型明显不符停止投入
已归档保留作方法案例，不再当作当前机会注明归档原因
页面打不开 ≠ 机会取消：先标“入口失效”，再检查招聘主体官网是否迁移、更新或发布更正。
TOOL 04

过期机会清理规则：满足一项，就停止标记“可行动”

  • 官方截止时间已过。
  • 官方页面明确显示报名结束、名额结束或活动结束。
  • 原始入口失效，且同一发布主体下未找到替代入口。
  • 只有转发或截图，无法追溯到原始来源。
  • 资格条件与个人档案明确不符。
  • 同一机会重复出现，只保留证据等级最高的一条。

删除

明显不适用、重复、虚假或无法追溯来源的内容。

归档

已结束但适合作为公告读法、材料准备或渠道入口案例的内容。

归档时多写一句：“为什么结束 / 为什么不适用 / 下次遇到同类机会先看什么。”你的旧记录才会变成经验，而不是垃圾链接。

THURSDAY ROUTINE

建议每周四固定更新，周末只处理已经筛过的机会

COMMUNITY CO-BUILD

社群共建的不是“岗位海”，而是有效入口和核验记录

每周一个主题

只选一个城市或一个行业，避免群里堆满无法处理的链接。

提交四个字段

原始 URL、检索日期、适用人群、最需要核验的问题。

先线索后入库

群成员提交先标“线索”，回到原始来源核验后才进入附录。

可以在群里问

  • 这个入口是否已迁移？谁找到了官方替代页？
  • 公告的哪一条资格原文容易误读？
  • 同一城市还有哪些主管部门或单位入口？

不能在群里承诺

  • “这个岗位你肯定能投 / 一定能过审核。”
  • “进群就有内推、offer 或全部岗位。”
  • “项目经费就是个人能拿到的补贴。”
