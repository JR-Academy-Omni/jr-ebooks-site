HOW TO USE

先看：求职不是依次学完所有技术

正确顺序是先选一组相邻岗位，再用真实 JD 反推技能、项目和简历。你不需要同时成为 Developer、Data Analyst、Cyber Analyst 和 AI Engineer。

1+2
一个主投方向，两个相邻备选。例：主投 Data Analyst，备选 BI Analyst / Reporting Analyst。
20
先收集 20 条真实 JD，再决定学什么。单条 JD 可能写得夸张，重复项才是市场信号。
2
一个能深挖的主项目，一个能证明专项能力的小项目。数量多不等于可信。
全书统一判断标准岗位搜索页的数量有重复、有相邻岗位，不能当市场人口普查；广告薪资有 base、package、含 super 和合同日薪之分。本书只把它们当“当日在招证据”，所有可变信息都标核验日期。

先定位

用专业基础、英语沟通、工作权利和可展示经历筛选岗位。

再举证

项目、GitHub、报告、测试记录和 STAR 故事必须能证明你做过。

最后扩大投递

先把匹配度和材料打磨到位，再提高数量；每周根据漏斗数据复盘。

CHAPTER 01

市场实况：机会还在，但 IT 求职竞争变强

32%
2025-26 澳洲 IT 行业招聘率；全行业为 49%。
16%
IT 雇主预计未来 3 个月增员的比例。
34%
招聘中的 IT 雇主每岗收到至少 20 份申请。

这三个数字说明：不是“IT 没工作”，而是企业招聘更克制、候选人更多。泛泛写“熟悉 Python / AWS / ChatGPT”不够，招聘方更容易选择能展示完整交付、沟通和验证能力的人。

AI 的真实位置Jobs and Skills Australia 的全国研究认为，短中期 GenAI 更可能增强而不是整体替代工作。对 IT 求职者，AI 是代码、分析、文档和支持流程中的效率工具；基础原理、结果验证、隐私和责任仍由人承担。

CHAPTER 02

七条入口：不要把“IT”只理解成写代码

01 SOFTWARE

软件开发

  • 适合：愿意长期写代码、调试和维护系统。
  • 基础：一门语言、Web/API、数据库、Git、测试。
  • AI 变化：辅助编码、Review、测试与 AI 功能集成。
02 DATA

数据与 BI

  • 适合：喜欢从数据回答业务问题。
  • 基础：Excel、SQL、Power BI、数据质量、表达。
  • AI 变化：加速分析，但口径、验证和解释更重要。
03 CLOUD

云与 DevOps

  • 适合：喜欢自动化、系统可靠性和排障。
  • 基础：Linux、网络、AWS/Azure、CI/CD、脚本。
  • AI 变化：部署 AI 服务、监控成本与性能。
04 CYBER

网络安全

  • 适合：关注风险、证据和持续监测。
  • 基础：网络、操作系统、日志、SIEM、事件响应。
  • AI 变化：数据泄露、Prompt Injection 与新型攻击面。
05 QUALITY

测试与质量工程

  • 适合：擅长找边界、复现问题和推动修复。
  • 基础：测试设计、API、SQL、缺陷管理。
  • AI 变化：自动化增强，AI 输出质量成为新测试对象。
06 BA / PRODUCT

技术业务分析

  • 适合：能在业务与技术之间翻译需求。
  • 基础：访谈、流程、User Story、UAT、Stakeholder。
  • AI 变化：识别自动化机会并定义可验证需求。
07 SUPPORT

IT / Application Support

  • 适合：喜欢排障、服务用户和积累系统经验。
  • 基础：M365、设备、权限、网络、工单与沟通。
  • AI 变化：Copilot、知识库和工单自动化进入日常。
HOW TO CHOOSE

主投、备选、保底

  • 主投：与你现有证据最匹配。
  • 备选：共享 60% 以上技能。
  • 保底：进入行业后仍能积累目标能力。
示例组合
主投：Junior Data Analyst
备选：BI Analyst / Reporting Analyst
不建议同时投：SOC Analyst / Frontend Developer

理由：前三者共享 SQL、Power BI、数据质量和业务表达；后两者需要另一套作品证据。
CHAPTER 03

岗位路线卡（一）：开发、数据、云

软件开发

当前样本：工程基础仍是第一门槛

Graduate Software Engineer 搜索页显示 613 条结果。Tactiv 的 Brisbane graduate 岗广告为 AUD 78k-82k，强调 hands-on coding、cloud 和真正交付产品；SEEK 的 13 个月 graduate 项目广告为 AUD 82k + super + bonus。样本说明 AI 没有替代编程、调试、测试和协作。

准备优先级：语言与数据结构 → API/数据库 → Git/测试 → 部署 → AI-assisted development。项目要能解释错误处理、权限、测试和上线，不只展示聊天框。

数据与 BI

当前样本：SQL、Python、平台与业务解释一起出现

Junior Data Analyst 搜索页显示 270 条结果。Ploomo 的 Junior Analytics Engineer 广告为 AUD 80k-90k + super，明确写 SQL、Python、Snowflake pipelines；其他样本强调 Azure、数据集成、Power BI 和数据治理。

准备优先级：Excel/SQL → Power BI → 数据清洗与质量 → Python → 云数据平台。AI 可以辅助写查询和归类，但必须展示核对口径、异常和结论的过程。

云与 DevOps

当前样本：junior 标题少，基础设施责任不轻

Junior DevOps Engineer 搜索页显示 142 条结果，并混有软件和云岗位。广告常见 Linux、cloud-native、可靠性、自动化与系统集成。求职者需要用部署证据证明能力，而不是只列 AWS 服务名。

准备优先级：Linux/网络 → 一朵云 → Docker → CI/CD → IaC/监控。AI 相关加分项是部署模型服务、日志与成本治理，但不能代替系统基础。

来源：SEEK Graduate Software Engineer、Junior Data Analyst、Junior DevOps Engineer 搜索页；核验 2026-10-28。薪资为具体广告口径，不是市场中位数。

CHAPTER 03

岗位路线卡（二）：安全、测试、BA、Support

网络安全

别从“黑客工具”开始

当前 Junior Cyber Security 搜索页显示 345 条结果，样本包含 Azure 环境下的 Graduate Cyber Analyst、第三方风险和项目协调。先掌握网络、身份权限、日志和事件响应，再选 SOC、GRC 或 Cloud Security。

测试与 QA

能就业，但不要只做手工执行

澳洲约有 9,100 名 Software Testers。当前岗位出现 Playwright、TypeScript、CI/CD、REST API、Postman、移动端自动化，也仍有 Junior Test Analyst。最佳定位是“测试设计 + API + 基础自动化 + 一个业务专项”。

技术 BA

需求不是会议纪要

Junior BA 搜索页显示 354 条结果。当前样本横跨保险数字化、医疗实施、Council graduate、系统支持；常见任务是需求访谈、流程分析、UAT、backlog 和技术业务对齐。

IT / App Support

仍是现实的第一份 IT 工作入口

IT Junior System Support 搜索页显示 964 条结果。样本覆盖 Help Desk、Junior System Admin、Application Support 和 IT Graduate，常见 M365、设备、权限、网络、云和客户沟通；部分 graduate 岗已写 cloud、AI、automation、security exposure。

留学生先看资格安全、测试和 BA 中有不少 Federal Government / Defence 合同，常要求 Australian Citizenship 或 Baseline 以上 clearance。看到薪资高、合同长也不要立即准备，先看资格栏。

来源：JSA Software Testers occupation profile；SEEK Junior Cyber Security、Test Analyst、Automation Tester、Junior Business Analyst、IT Junior System Support 页面；核验 2026-10-28。

CHAPTER 05

做项目：项目不是功能清单，是可追问证据

一个合格项目至少回答六件事：谁遇到什么问题、你负责什么、为什么这样设计、怎么验证、哪里失败过、下一步怎么改。

PROJECT A

求职投递管理器

React/Node/PostgreSQL；登录、岗位状态、提醒、筛选、测试与部署。AI 只负责提取 JD 草稿，用户确认后入库。

PROJECT B

招聘数据看板

SQL/Python/Power BI；清洗岗位样本、技能词表、城市分布、数据质量检查和可复现说明。

PROJECT C

Web/API 质量套件

Playwright + TypeScript + Postman/Newman + GitHub Actions；功能、API、回归和报告；加一组 AI 输出稳定性测试。

项目验收 10 项

  • README 第一屏说清用户、问题和结果
  • 有架构或数据流程图
  • 安装和运行步骤可以复现
  • 有真实错误处理，不只跑 happy path
  • 敏感信息不进仓库
  • 至少一层测试自动化
  • 有部署或可观看的演示
  • 写明技术取舍与已知限制
  • AI 参与部分与个人决策分开说明
  • 准备 5 个可能被追问的问题
不要做的项目照视频逐行抄、没有数据来源、没有错误处理、README 只有技术栈、AI 一键生成后自己解释不了。招聘方不需要再看一个换皮 Todo App。
CHAPTER 06

简历：把“学过”改写成“做过并验证过”

弱表达可信表达
熟悉 React、Node、AWS 和 ChatGPT。用 React、Node 与 PostgreSQL 构建投递管理器；在 AWS 部署 API，并为权限、重复提交和失败重试编写测试。
使用 AI 提高开发效率。用 Copilot 起草测试边界，再人工补充权限与异常场景；所有生成代码通过 Review、单元测试和静态检查。
负责数据分析和报表。清洗 18,000 行订单数据，统一日期与产品口径；用 SQL/Power BI 交付 4 页看板，并记录 12 条数据质量规则。

两行项目公式

第 1 行：为【用户/业务问题】使用【关键技术】交付【可运行成果】。
第 2 行：通过【测试/数据/流程】验证【质量指标】，并处理【一个真实难点】。

AI 使用句式：
在【具体任务】使用【工具】生成初稿；由我通过【验证方法】修正，最终【真实结果】。

简历顺序

姓名与联系方式 → 2-3 行定位 → Skills → Experience / Projects → Education。应届生谁更强就把谁放前面；不要写与目标岗无关的技能长墙。

LinkedIn / GitHub

三处岗位定位一致；Featured 放主项目；GitHub pinned 仓库不超过 4 个；README、commit 和联系方式可正常打开。

  • 每个 bullet 以动作开头
  • 数字能解释来源，不虚构百分比
  • 删除“hard-working、passionate”等无证据形容词
  • 根据 JD 替换排序，不批量堆关键词
  • PDF 文件名包含姓名与岗位，不写 final_v7
CHAPTER 07

找岗位：每周经营一个求职漏斗

A优先投

核心要求约 70% 以上匹配，工作权利、地点和硬性资格全部通过。投入 30–45 分钟定制首屏、项目顺序与联系消息。

B常规投

核心职责能做，有 1–2 个可补的工具差距。投入 15–20 分钟调整关键词与证据，不为每条广告重写整份简历。

C先验证

岗位跨度较大、经验门槛偏高或资格表述不清。先用 5 分钟查公司官网和硬约束，验证后再决定是否投入。

来源用途动作
SEEK / LinkedIn发现岗位、建立关键词和提醒。当天发现当天核验公司官网。
公司 Careers确认岗位仍开放、读取完整资格。优先从官方页面提交。

漏斗诊断

  • 投递多但无 phone screen：检查资格、岗位定位和简历首屏
  • 有 phone screen 但无下一轮：检查动机、表达与工作权利回答
  • 技术面频繁失败：检查基础、项目深度和现场思路
  • 终面失败：检查 STAR、协作故事、Reference 和岗位匹配
CHAPTER 08

面试：准备故事库，不背一套万能答案

行为题 8 个故事

失败、冲突、模糊需求、时间压力、主动改进、学习新技术、影响他人、客户问题。每个故事写 Situation / Task / Action / Result / Reflection。

项目深挖 8 个问题

为什么做、你的贡献、数据从哪来、为什么选技术、最难 Bug、如何测试、如何部署、规模扩大十倍怎么办。

AI 使用问题：诚实回答四步

任务：我在写 Playwright 回归测试时，用 Copilot起草 page object。
边界：测试策略、断言和敏感数据规则由我定义。
验证：我逐段 Review，并用故意失败的场景确认测试真的能抓住问题。
结果：减少重复样板代码；权限和并发场景仍由我手工补齐。

不要回答：我什么都让 AI 做，但我会检查。

CHAPTER 09

Offer、工作权利与资格核验

比较 Offer 时看完整条件

项目要确认的问题
薪资口径是 base、base + super、total package，还是合同日薪？Bonus 是否保证？
合同Permanent、fixed-term、contractor？试用期、通知期和加班安排是什么？
工作方式每周几天到办公室？异地搬迁、on-call、轮班是否明确？
成长直接经理是谁？前三个月交付什么？是否有导师、培训与证书预算？
资格工作权利、背景调查、Citizenship、clearance 是否满足？
签证与工作权利不要根据同学、论坛或旧文章判断。用 Home Affairs / VEVO 核对个人条件，并对申请表如实回答。Security clearance 是另一套资格，Federal Government / Defence 岗位可能要求 Citizenship 与特定级别许可。
